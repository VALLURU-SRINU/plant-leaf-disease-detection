Model Architecture & Methodology

PlantDoc AI leverages Transfer Learning with Google's MobileNetV2 architecture fine-tuned on the PlantVillage foliar disease dataset.

1. Why MobileNetV2?

MobileNetV2 uses depthwise separable convolutions with inverted residual blocks and linear bottlenecks. This drastically decreases the model parameter count to approximately 3.5 million parameters (~14 MB), while preserving over 95% Top-1 classification accuracy. It executes inference in under 50ms on commodity CPUs and mobile devices.

Neural Network Pipeline

  1. Input: Normalized RGB image (224 × 224 × 3)
  2. Base Backbone: MobileNetV2 feature extractor pre-trained on ImageNet
  3. Pooling: GlobalAveragePooling2D reducing spatial dimensions
  4. Regularization: Batch Normalization + Dropout (0.35 rate) to prevent overfitting
  5. Dense Representation: Fully connected 256-unit layer with ReLU activation
  6. Output: Softmax activation producing class posterior probabilities

2. Training & Validation Protocol

The model uses real-time data augmentation including random rotations (±25°), zoom (±20%), horizontal flipping, and shear. Optimization is driven by Adam optimizer ($lr=5\times 10^{-4}$) with categorical cross-entropy loss and dynamic learning rate reduction on plateau.
